# 地址对齐诊断记录

本文只讨论当前 1.0 项目：57 类地址标签、本地 BERT、SQLite 和五字段 Web 接口。按既定要求保留原教学代码的主要算法，下面区分运行能力与识别效果。

## 1. 从输入到展示

```text
原始地址 → tokenizer → BERT 逐位置分类
         → 整理省市区县等字段 → SQLite 校验补全
         → API 返回 JSON → 网页显示
```

可以把它想成接力：模型负责给文字贴标签，后端整理和核对，网页负责展示。最后显示为空，可能是任意一棒没有传好，不能只怪模型。

当前接口返回 `province/city/district/town/detail` 五项，网页读取同名字段。姓名和电话不属于当前接口输出。

## 2. 数据与标签

训练输入是 `data/raw/data.txt`：一行“文字 标签”，空行分隔样本。现有数据 10,826 条，划分为训练 8,660 条、验证 1,083 条、模型评估 1,083 条。

`config.LABELS` 保持 57 项。当前 TXT 中部分通用字段在读取时作临时映射：`name/phone` 作为 `O`，`detail` 作为 `poi`；磁盘文字及标签不修改。这只能让数据进入模型，不会自动得到道路、单元、楼层等细分类的真实标注。

数据仍只覆盖部分细分类，因此“模型输出有 57 类”不等于“每一类都学到了可靠能力”。细分类标注方案待完善。

## 3. 首字监督信号缺失

当前 `_align_labels_with_tokens()` 使用 `if word_idx`。原文首字的编号是 0，Python 将它当作假，因此首字标签被设为 `-100`，不参与损失计算。

相当于每道题的第一个空不批改，会丢掉一部分学习信号。这个原文档问题按要求保留。

## 4. token 与字符可能错位

token 是模型读取的单位，不保证始终与原字符一一对应。空格和某些特殊字符可能被过滤；超长输入也会截断。

当前 `predict()` 只追加产生 token 的位置，后处理却按原文本下标切片。若中间有被跳过的字符，预测标签可能与原文位置错开。默认上限是 64 个 token，其中还包括特殊 token。

## 5. 训练状态与模型选择

- 保存和加载的是模型权重，不含优化器状态、累计轮次等全部进度，不能当作完整断点续训。
- 每次运行 `best_valid_metric` 从 0 开始，不会自动继承历史最佳成绩。
- 训练结束后直接使用最后一轮模型做后续评估，没有重新加载已保存的最佳模型。
- 分类头尺寸不匹配时仅复用 BERT 参数，新分类头需要重新训练。能够启动服务不表示分类头已经训练成熟。

权重像学生记住的知识，优化器状态和轮次像学习进度表；这里只保存了前者。

## 6. 指标的含义和局限

当前指标是逐 token 的 macro F1：先为每个类别计算 F1，再平均。它不直接表示整条地址全对，也没有衡量数据库校验后最终字段的准确率。

未固定参与平均的类别集合，实际出现或被预测的类别可能随模型变化，影响不同轮次的比较。

loss 在每批内部按有效 token 平均，跨批时又按样本数汇总；当地址长度不同时，它不严格等于全数据的平均 token 损失。

## 7. 数据库与字段整理

1. 同名地区查询没有充分结合已知省市筛选。例如“朝阳区”存在多个候选，直接取一个候选可能产生上下级冲突。
2. 道路、路口和乡镇街道都映射到第 5 类字段，但数据库第 5 级主要是行政乡镇街道；普通道路可能查不到而被清空。
3. `check_address()` 查询失败时清空字段却返回 `True`，这个结果不能严格理解为“校验成功”。
4. `predict()` 去掉 B/I/E/S 前缀，后处理无法完整区分同类型实体的边界。
5. 同一输出字段出现多个片段时，后面的赋值会覆盖前面的片段。

这些是算法层面的限制，本轮未额外改造。

## 8. 缓存与随机性

处理目录存在时直接加载缓存，不检查原始数据或标签表是否改变。修改训练输入后，应重新生成对应数据缓存。

划分、初始化和训练打乱顺序没有统一固定随机种子，因此重复运行可能得到不同结果。

## 9. 已验证到什么程度

曾用当前 57 类模型在 CUDA 上以 batch 128 完成 3 次参数更新、2 批验证以及权重保存重载；这是运行检查，没有执行完整 10 轮训练。

Web 首页、接口文档和预测请求已完成 HTTP 200 检查。HTTP 200 说明请求被正常处理，不代表抽取出的内容一定正确。

模型训练质量仍需在正式训练后，以独立样本和最终字段结果评估。当前不保留独立的自动化测试脚本；训练器内的评估流程仍是训练代码的一部分。
