# 地址对齐项目说明

本项目以《实战之地址对齐1.0.docx》为基础，使用本地 BERT、57 类标签、FastAPI 和 SQLite。

## 阅读顺序

| 文档 | 内容 |
| --- | --- |
| [01-诊断记录.md](01-诊断记录.md) | 当前训练、数据处理、字段整理和地区校验的机制与局限 |
| [02-文件与函数说明.md](02-文件与函数说明.md) | 运行文件、自定义函数以及网页交互，保留第 1–11 节 |
| [03-标签与数据流程.md](03-标签与数据流程.md) | 标签字母、全部 57 类编号、TXT 格式、token 对齐和训练预测流程 |

## 使用要点

- 训练输入：`data/raw/data.txt`；模型参数：`finetuned/`；地区库：`data/region.db`。
- `config.DEVICE` 可设置为 `cpu`、`cuda` 或 `mps`，训练和默认推理共用。
- TXT 通用字段读取时作映射，细分类标注方案仍待完善。
- 独立自动化测试文件已移除；训练器的验证与模型评估流程保留。
- 已验证小规模训练及 HTTP 请求可执行，未完成正式训练效果评估。

运行命令见根目录 [README.md](../README.md)。
